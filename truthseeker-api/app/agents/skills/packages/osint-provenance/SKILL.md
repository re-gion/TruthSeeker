# 情报溯源与证据图谱 Skill

## 适用场景

用于 URL、域名、账号、声明、文本线索与公开来源的威胁研判和溯源图谱构建。

## 输入边界

把当前检材、外部来源、模型推断边和 RAG 参考分开；模型推断关系必须显式标识，不能伪装成已核验来源。上游已核验结论（电子取证阶段经逻辑质询核验的检材鉴伪结论，含图像与文本 AIGC 检测）属于可信输入：涉及检材真伪、伪造性或是否 AI 生成时必须以其为准并写明上游归因，不得独立重建分歧的低置信判断，也不得把复用取证结果得到的数字包装成本阶段独立推断；确有冲突情报时必须显式写出冲突点与依据。报告开头会出现系统确定性注入的“上游已核验结论引用”小节，不得自行生成或改写该小节。检材本体的像素级/频谱级鉴伪不是本阶段职责。对品牌、机构、产品等实体做存在性判断必须以实际执行的搜索覆盖为准并列出搜索清单：已执行实体独立检索且全部零命中的，应倾向判定“虚构品牌”或“品牌被冒充”（零命中倾向虚构；仅命中与检材无关的官方存在倾向被冒充），不得停留在“未检出/未确证”的模糊表述，也不得在未执行实体独立检索时断言品牌虚构。经验/类案 RAG 要求但当前工具配置不支持的验证动作，只需如实标注“当前工具不支持该验证动作”，未执行不构成缺陷。

## 标准步骤

1. 从案件目标和检材提取可验证实体与声明。
2. 生成脱敏查询并交叉核验来源、时间和主体。
3. 建立带引用的实体关系，检查孤立节点与无引用边。
4. 汇总确定性风险分数、图谱质量和后续补证路径。

## 允许工具

使用运行时提供的 Exa、VirusTotal、WhoisXML、文本分析、类案 RAG、个人经验 RAG 和确定性图谱构建器。

## 证据门槛

外部来源必须保留引用和状态；降级、无密钥或失败调用不能写成安全结论。RAG 不替代当前 URL、域名或声明核验。

## 禁止事项

不得扩写未出现的实体，不得用搜索摘要代替原始来源，不得让 Skill 改写威胁分数与公共图谱协议。

## 输出要求

说明自主情报推理、外部结果、来源可信度、图谱质量、关联风险和复核建议，并保持引用边界清楚。

## 自检清单

- 核心实体和边是否有来源。
- 推断边是否显式标识。
- 时间关系是否服从确定性校验。
- 降级来源是否被如实披露。

## 降级策略

Skill 不可用时继续系统提示词路径，把加载状态写入日志与结果，不生成采用 Skill 的表述。
