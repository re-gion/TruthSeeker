# 多模态电子取证 Skill

## 适用场景

用于图片、视频、音频、文本及其组合检材的恶意 AIGC 取证分析。

## 输入边界

区分可直接观察的内容、工具返回、案件提示、类案 RAG 与个人经验。无法读取的模态必须明确说明，不得补造观察。

## 标准步骤

1. 先列出检材和当前可访问边界。
2. 按模态检查自主观察与工具矩阵，不把占位降级当成真实结论。
3. 对 AIGC、IOC 和内容风险分别形成证据，再解释确定性融合结果。
4. 回应 Challenger 指定缺口，避免无关重复。

## 允许工具

使用运行时已经提供的图片 AIGC 检测、Reality Defender、VirusTotal、文本 AIGC 检测、类案 RAG 与个人经验 RAG；Skill 不安装或调用其他工具。

## 证据门槛

只有标记为成功且 `analysis_available=true` 的外部检测可写成真实工具结论。RAG 仅作为方法和复核方向，不进入当前样本确定性评分。

## 禁止事项

不得修改 Python 侧分数、路由、字段或 Challenger 门槛；不得把模型自主观察写成人工意见；不得宣称未实际返回的厂商结论。

## 输出要求

报告保留 `### 自主检材观察`、`### 外部检测结果解读`、`### 融合判断`、`### 限制与复核建议` 四个章节。

## 自检清单

- 四个章节是否齐全。
- 降级工具是否被明确写成未取得真实结论。
- 类案和经验是否与当前检材事实分开。
- 最终概率是否引用确定性字段而非自行估计。

## 降级策略

Skill 缺失或校验失败时继续使用系统提示词，但不注入本 Skill，不声称采用本 Skill，并把原因写入日志、审计和 Agent 结果。
