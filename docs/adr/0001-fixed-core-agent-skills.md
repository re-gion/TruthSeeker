# 四 Agent 固定绑定可降级的核心 Skill 包

TruthSeeker 的四个 Agent 将各自固定绑定一个版本化核心 Skill 包，而不在第一版引入动态 Skill 路由。系统提示词继续定义身份与边界，Skill 定义专业方法，确定性代码继续拥有评分、路由、硬门槛和协议的最高优先级。Commander 使用一个“研判指挥与协同编排 Skill”，内部显式区分最终裁决、人机协同主持和脱敏经验提炼三个工作流。

Skill 缺失、版本不兼容或校验失败时允许 Agent 仅凭系统提示词继续运行，但必须在实时日志、审计记录和最终报告中标记降级，不得声称本轮采用了 Skill。选择固定绑定是为了先得到可解释、可测试、可审计的能力闭环；动态 Skill 选择保留为后续扩展。

## Consequences

- 每个 Skill 同时需要可读的 `SKILL.md` 契约与代码侧加载、注入、校验实现。
- Agent 卡片展示绑定 Skill 与版本；日志和报告只展示实际加载、执行或降级证据，不公开完整内部规则。
- 第一版验收同时包含离线契约测试和可选的真实 Kimi 开关对照评测；真实外部调用不成为 CI 硬依赖。
